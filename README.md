| **[HDA-DehazeNet](https://github.com/ProjectGopi/HDA-DehazeNet)** | Hybrid physics-informed image dehazing and object-detection framework | Dark Channel Prior + residual U-Net (~29M params) that learns only the correction to the physics estimate; **15.18 dB PSNR, +1.87 dB over classical DCP (p < 0.001, paired t-test on a synthetic set)**; multi-component loss (MSE + SSIM + VGG-16 perceptual); YOLOv8 downstream evaluation; **118 FPS** on GPU; Streamlit demo | `PyTorch` `OpenCV` `YOLOv8` `Streamlit` |

| **[AutoInsightAI](https://github.com/ProjectGopi/AutoInsightAI)** | Full-stack platform for automated dataset analysis | Upload and manage datasets, automated profiling, anomaly detection and ML-driven insights; React dashboard with charts and dark mode; async FastAPI processing | `React` `FastAPI` `PostgreSQL` `Pandas` `scikit-learn` `Tailwind` |
