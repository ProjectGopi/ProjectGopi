### 🔍 What each one does

| Project | What it is | Highlights | Stack |
| :-- | :-- | :-- | :-- |
| 🌫️ **[HDA-DehazeNet](https://github.com/ProjectGopi/HDA-DehazeNet)** | Hybrid physics-informed image dehazing and object-detection framework | Dark Channel Prior + residual U-Net (~29M params) that learns only the correction to the physics estimate · **15.18 dB PSNR, +1.87 dB over classical DCP (p < 0.001, paired t-test on a synthetic set)** · multi-component loss (MSE + SSIM + VGG-16 perceptual) · YOLOv8 downstream evaluation · **118 FPS** on GPU · Streamlit demo | `PyTorch` `OpenCV` `YOLOv8` `Streamlit` |
| 🛡️ **[StaticGuard](https://github.com/ProjectGopi/StaticGuard)** | AST-based static analysis and defect detection framework for Java | **39 rules across 6 categories** (code smells, dead code, security, naming, metrics, duplication) · cyclomatic + cognitive complexity and maintainability index · severity-ranked findings with fix suggestions · JSON + interactive HTML dashboard · CI-friendly exit codes | `Java 17` `JavaParser` `Jackson` `Maven` `JUnit` |
| 👁️ **[SmartVisionAI](https://github.com/ProjectGopi/SmartVisionAI)** | End-to-end document classification and analysis dashboard | Custom PyTorch classifier for document images · Tesseract OCR text extraction · GPT-generated summaries and insights · full training pipeline with feature extraction and evaluation | `PyTorch` `scikit-learn` `OpenCV` `Streamlit` `OpenAI API` |
| 📊 **[AutoInsightAI](https://github.com/ProjectGopi/AutoInsightAI)** | Full-stack platform for automated dataset analysis | Upload and manage datasets, automated profiling, anomaly detection and ML-driven insights · React dashboard with charts and dark mode · async FastAPI processing | `React` `FastAPI` `PostgreSQL` `Pandas` `scikit-learn` `Tailwind` |
| 🚗 **[AutoIntelAI](https://github.com/ProjectGopi/AutoIntelAI)** | ML-powered car discovery backend | Recommendation engine (content-based features + KMeans) · natural-language search intent parsing · Random Forest resale prediction · Isolation Forest price-anomaly detection · ownership cost estimation · REST API | `FastAPI` `SQLAlchemy` `scikit-learn` |
